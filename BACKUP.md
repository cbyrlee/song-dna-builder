# Backup and Restore

## Primary copies

- Google Docs master source: https://docs.google.com/document/d/17RIfmQ9SNrhxZlDvkDr_qFJwcwpa0PJuVQa7ig9hc2Q/edit
- Replit project: https://replit.com/@chrisbyerley/Lyric-Architect
- Live Replit deployment: https://lyric-architect--chrisbyerley.replit.app

## Preset protection

Use the app's Song DNA JSON export for any preset you care about. The JSON backup preserves dropdown selections, locks, and the raw mind-dump so it can be imported later to reconstruct the song configuration.

## Recovery order

1. If the live Replit app works, use it normally.
2. If local presets disappear, import a saved Song DNA JSON file.
3. If the hosted app is lost, rebuild from the Google Docs master source.
4. Keep this GitHub repository as the version-history location for future source updates.
