# Song DNA Builder

A configurable song and rap prompt builder that generates coordinated lyric XML, companion beat XML, and a combined song package from shared Song DNA.

## Backups

- Live app: Replit deployment
- Master source: Google Docs backup
- Durable song presets: export/import Song DNA JSON

## Core features

- Large dropdown-driven creative option set
- Section-level and global randomization
- Per-field locks to protect selections from randomization
- Raw mind-dump input
- Lyric XML output
- Companion instrumental XML output
- Combined full song package XML
- Semantic wildcards including imaginary recording locations, spatial/physical/psychological descriptors, motion, visual associations, density/space language, impossible production instructions, and emoji seeds
- Local preset save/load/duplicate
- JSON export/import for durable preset reconstruction

The app is designed so lyric and instrumental prompts interpret the same shared Song DNA rather than acting as unrelated generators.
